Headers:  User-Agent = 浏览器UA

## 3. 数据模型（`models/schemas.py` 扩展）

排列5规则：每期 5 位数字（每位 0-9，顺序即开奖顺序），如 `26229期: 2 8 0 5 4`

```python
# 历史记录（兼容现有 HistoryRecord）
HistoryRecord: period="26229", numbers=[2,8,0,5,4], date="2026-08-27"

# 规律条目（新增，替代/扩展 Post）
PatternItem:
  period: str          # 所属期号
  blogger: str         # 来源博主
  content: str         # 规律原文（如"第一位看好大数"）
  source_url: str      # 来源链接
  extracted_at: str    # 采集时间

# 规律特征（analyzer 提炼后挂到 Pattern）
Pattern 扩展: pattern_type（和值/大小/奇偶/定位/跨度/012路/连号/重号...）, features{}
```

**VCP 记忆库调整**：观点库由"帖子"升级为"规律条目"（per-period patterns，支持去重合并计数、跨期重复统计）。

## 4. 采集模块（`agents/collector.py`）

```
fetch_pl5_history(years=2)
  → 请求 inc/history.php?limit=730（UA+Referer，gb2312）
  → 解析 t_tr1 表格 → HistoryRecord[]（5位数字校验）
  → vcp.save_history()

fetch_blogger_patterns(url, periods)
  → 爬取博主规律页面（用户确认 URL 后定解析规则）
  → 清洗：去广告/无意义/长度过短
  → PatternItem[] → vcp.save_patterns()
```

**去重策略**（针对"每期~100条、跨期重复"）：
- 同期同文本 → 合并，支持人数 +1
- 跨期重复 → **保留**（这是"规律复现率/稳定性"的统计基础，不丢信息）
- 存储带 `first_seen_period`，便于后期统计

## 5. 分析模块（`agents/analyzer.py`）

排列5规律分类体系（`_evaluate_single_pattern` 按类型实现数值验证）：

| 类型 | 例子 | 验证逻辑 |
|---|---|---|
| 和值 | "本期和值看好18-22" | 5位之和落在区间（0-45） |
| 大小 | "第一位出大数" | 某位 > 4 为大 |
| 奇偶 | "第3位出偶数" | 某位 %2==0 |
| 定位胆 | "第5位出7" | 某位 == 7 |
| 跨度 | "跨度小于5" | max-min < 5 |
| 012路 | "第2位0路" | 某位 %3==0 |
| 连号/重号 | "有连号""有重号" | 相邻差1/存在重复 |

- 博主口语化描述 → 结构化特征：先用**规则归一化**（关键词表），效果不足再上**大模型提炼**（M2 可选）
- 合并去重 → 支持度统计（沿用 `_merge_patterns`）
- 回测：`_backtest_patterns` 按类型调用验证逻辑（M2）

## 6. 决策模块（`agents/decision.py`）
