## 1. 目标

过滤阶段三步不变：**① 判走势图 → ② 过滤无标注 → ③ 正确切分**。只输出「有标注 + 能正确定位目标期行」的窄条（含上一期 + 目标期），交给视觉模型。

---

## 2. v4 实测教训（v5 修订的依据）

### 2.1 开奖对拍不能当定位门槛（只记录）

v4 设想：多期开奖对拍（读每行 5 开奖数字 vs 权威开奖）验证纵向定位，前 10 期 ≥5 次 ≥3/5 容错通过。

**实测推翻了它**：对拍要逐列读数字 → 逐列读要精确列位（detect_columns 灰度投影）→ 列位受期号/和值列混入影响，产生**整串 ±1 偏移**。这个偏移是**系统性的**（某张图列位偏，它所有行都偏），不是偶发。因此：

> **多期一致性无法区分「列位偏」和「期号读错」**——列位偏的图，多期对拍全低，会被门槛误剔，哪怕它期号已经清清楚楚定位到 calib 行。

冒烟 20 图中 4 张期号已定位到 26232/26233，却因对拍 ok_count<5 被拒。**结论：开奖对拍降级为仅记录（`CALIB_MIN_OK=0`），定位唯一判据 = 期号 OCR 锚定**。

### 2.2 「期号全废」是两群人，不能一刀切

去掉对拍门槛后，剩下被拒的都是「目标期行未定位」（最近 ~10 行无一行期号对上 calib/target/calib-1）。冒烟 20 图里 12 张如此，**全部是整图零期号命中**。细看是两群人：

| 人群 | 特征 | 该不该救 |
|---|---|---|
| A 真垃圾/鬼影 | 底行空、幻影行（页脚冒充行）；ASCII 渲染几近空白 | 该排除（本就不是可用走势图）|
| B 真走势图但字太小/太密 | 行网格完整、有标注、有开奖内容，但数字小到 CNN 宽条读不出一位对的 | 旧 v3 的 period-weak 桶（全量 285 张！）→ **该救** |

v3 对 period-weak（285）**不排除**、单独归「uncertain」——因为真走势图也可能读不出期号。v5 延续：B 群不能因期号读不出就丢。

## 3. v5 核心思路：两路判走势图

走势图的「身份证」是**结构**不是内容：行等距（横对齐）、列排布（列对齐）、左侧期号列、表格网格。这些 OpenCV 能可靠抓，且**内容无关**（字越小越糊，结构还在）。判定分两路：

```
┌─ A 路（先跑，OpenCV，内容无关）─────────────────────────┐
│ 识别网格结构 = 走势图？                                   │
│   - 行网格：一组等距横线族（表格行边界）→ rows / pitch     │
│   - 列排布：内容区横向投影 → 列结构（左侧期号区 + 开奖区）  │
│   - 鬼影/页脚行剔除：横线族一致性过滤                      │
│  非表格结构 → 排除（no-chart/junk）                       │
└─────────────────────────────────────────────────────────┘
┌─ B 路（A 通过才跑，CNN，内容锚）──────────────────────────┐
│ 最近 ~10 行逐行读期号 → 任一行对上 → 定位 calib 行         │
│   - 读法 = 「期号格放大 OCR」不是宽条 OCR（§4）            │
│   - calib 行 → target = calib + row_pitch → 横切窄条      │
│  全对上 → 无法定位目标行 → 排除（记录 reason）            │
└─────────────────────────────────────────────────────────┘
```

**A 路回答「是不是走势图」**（结构，不依赖读字）；**B 路回答「目标行在哪」**（内容锚，只要有任意一行对上）。两路解耦——不再要求「读出一堆期号才认它是走势图」。

### 3.1 A 路实测（OpenCV 网格结构）

长核形态学开运算只保留横跨大段的直线，把字/圆/博主笔迹（短线）全滤掉：

- 横线：横向长核（~0.5–0.6w）开运算 → 每行一条横线 → **等距横线族**。
- 竖线：纵向长核（~0.5h）开运算 → 列线（多数图不画全列竖线，竖线只作辅助）。

实测：
- 正常走势图：横线族 pitch≈160、std≈2 → 干净；竖线 3–5 条（只画区界）。
- **曾被疑为垃圾的 0ee3536d：横线族 pitch≈160、std 2.4 → 其实干净 → 它是走势图，v4 误判**。
- 页脚/边框：底行大横线 + 高密度块，与数据横线族间距不一致 → 可剔。

**结论：走势图判据主要靠「等距横线族」，不靠竖线数**（多数图不画列内竖线）。

> 注：当前 `process_one` 已做行检测（内容色掩码）+ no-grid 判定，实为 A 路的雏形。v5 是把它的行判据补强成「横线族一致性」（内容无关），并让鬼影/页脚行不污染。

### 3.2 B 路实测（CNN 期号锚）

- 期号锚命中率：单行 ~55%（20 图冒烟）；但**逐行读、最近 ~10 行里有任意一行对上**即可锚定，单行命中率的短板被行数摊薄。
- 期号锚比开奖锚可靠：开奖锚依赖列位（系统性偏移，§2.1）；期号在最左独立格，不依赖 5 列列位。

## 4. 期号为什么「整格放大读」，而不是宽条 OCR

v4 的 `period_pairs` 是取行带 × [0, 0.32w] **宽条**直接 OCR。两个反例：

1. **宽条混列**：小图/密图中 0.32w 内含 期号+和值+形态 多个数字列，OCR 整条放大 6× 后 CNN 把多列数字切成一串乱码（实测读 `9314`/`3835`，对不上任何期）。
2. **期号列位置不定**：部分博主期号列不在最左 32%，0.32w 截断丢字。

v5 读法：**用网格/结构把「期号格」框出来，只对这一格放大 OCR**。
- 期号格 x 范围：行内容区最左的独立数字串（期号）→ 用 A 路的列结构投影给出「期号区右界」（期号串与其后内容间的大空档）。
- 每格单独放大 6× 再 OCR → 小图期号从「整条乱码」变「单格清晰」。
- 期号格里的字是**打印字**（规整），本就比手写准；格小放大后 CNN 单字准确率显著高于宽条。

**这才是「让网格更明显」的真正用途**：网格给出格的精确边界，读格内内容（期号/开奖）才能精准放大。

## 5. v5 filter 流程

```
输入：img、lottery、target_period（calib = target-1 自动算）

A 路（结构，内容无关）
  1. 网格/行检测（OpenCV）
     - 行网格结构成立？ 不成立 → exclude no-chart
     - 行横线族一致性 → rows / row_pitch / row_half；鬼影/页脚行剔除
  2. 过滤无标注  process_one no-anno → exclude（博主没画规律，送视觉浪费）
     （status==cropped 才继续，语义=有行网格 + 有标注）

B 路（内容锚）
  3. 逐行读期号（最近 ~10 行，每行期号格放大 6× → OCR → match_period）
  4. 任一行期号 == calib/target/calib-1 → 定位 calib_row（优先级 calib → target-1行外推 → calib-1+1行）
     - 全无 → exclude（reason=period-unanchorable；记录，留给审计区分 A/B 人群）
  5. target_row = calib_row + row_pitch

切窄条
  6. 横切整块（期号列 + 5 开奖列，含上一期 + 目标期），3× 放大
  7. 写 strips/<stem>_strip.png + manifest.json + filter_report.json
```

**开奖对拍（`match_row_draw`）**：保留 `calib_anchor.py` 的函数，但只在 meta 里**记录**（`calib_draw`/`calib_match` 调试用），**不设门槛**。

## 6. 边界与回退

| 情况 | 处理 | 风险 |
|---|---|---|
| A 路不成立（非网格表/幻影） | exclude no-chart | 正确 |
| no-anno（无标注） | exclude | 正确 |
| B 路期号对上 calib/target/calib-1 | 定位 → 切窄条 | 无 |
| B 路最近 ~10 行**全零命中** | exclude period-unanchorable | **丢真图（人群 B 小图/密图）**：无法廉价定位；宁可丢不可错。全量跑后审计真占比，若高再加开奖 run 兜底（§8 待办） |
| 期号格放大后仍读不出（太糊/非打印字） | exclude | 该图视觉模型也难读，丢可接受 |

参数：

| 参数 | 默认 | 含义 |
|---|---|---|
| `LOOKBACK` | 10 | 期号读取倒数的行数 |
| `CALIB_MIN_OK` | 0 | 开奖对拍门槛，**默认关**（只记录）|
| `CALIB_MATCH_TH` | 3 | 单期对拍记录用阈值（不设门槛）|

## 9. 结论

- filter 定位 = **A 路（OpenCV 网格结构判走势图，内容无关，先滤）+ B 路（CNN 期号锚定目标行）** 两路解耦；
- **开奖对拍降级为记录**（列位系统性偏移使其无法当门槛，v4 实测）；
- 期号读法改**逐行期号格放大**，救人群 B（小/密真图）；救不了的是低价值密集截图 → 排除可接受；
- 宁可丢不可错：定位不到目标行就排除，绝不产出错位窄条冒充正确。
