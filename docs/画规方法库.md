- 画法类型: 斜连/框选胆码/定位
- 风格: 长跨度斜连走势图圈选大范围号码，再结合万位近期胆码定预测
- 画法描述: 在26157-26232期长跨度走势图上，用蓝色斜连线贯穿全图并圈选众多号码，且有多处红/紫圈选；同时在万位位置圈选胆码6、2、4，标注为近期万位多期圈选。
