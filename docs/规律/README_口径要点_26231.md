## 1. 命中口径

命中 = 博主写在**目标期行（最下行；走势图"最新在底部"，row0=最旧）**的**手写单押**数字，且「**位对 + 单码 + 实开该数**」三者齐全。

- 单码采集 = 一位只写 **1 个**能定位的数字。
- 多码（≥2 候选）/ 和值 / 组选 / 不定位（报号）/ 无画规 → 剔除出分母。

## 3. 规律库

只保留 **`REPEAT`（签名串重复）/ `SWAP`（万十互换）/ `SLANT`（同列等差）** 固定枚举、逐个机械复算。

- 旧的 `RHYTHM`（节奏）/ `MOTIF`（动机）**已废弃**，并入 `REPEAT`。
- 每条规律必须是**确定性输出**，不是"看着像就认"。

## 4. 🔴 关键边界（最容易被写反）

- **签名串重复 = 合法规律**：因为它是**博主亲手画在这张图上的轨迹**（291 画两次 / 1421 两列同型）——博主自己的节点重现，不是外来的。
- **扫开奖历史表找"先例" = banned（幻觉）**。区别只有一点：博主有没有**画出来**那条重复签名/轨迹线。
- 因此**读博主画规要从原图把轨迹线读全**；链条读不全（漏前面几个节点）是当初误判"巧合"的根因。

## 5. 第七步「画规自证复现」= 值保真 + 逻辑自洽（两层）

- **值保真**：只验"链项 == 开奖表"。不够——任何一串真开奖数字都满足。
- **逻辑自洽**：预测必须是规律库某模式的**确定性输出**；推不出 → 判 **coincidence（巧合命中）**，即使中了也**不列规律**；链条含"模式未用到的节点"（≥2 悬空）→ 判**超伸/装饰**（疑读入红线穿过的点）。
- 26231 自证结果：**可复现且中 3 / 巧合 1 / 未中 1 / ds-fail 0**。

## 6. 位置判定

用开奖表链条反推哪些列成立（`draw_tbl[期号][位]==链数`，某列**唯一成立**即数学排他）。

**不要用"像素 x 中心对 `filter_report.cols`"**——被期号/和值列污染，富老师_0 就是被它翻错成千位。**勿因"某数只在某列"推博主押那列**——博主可在任意格圈。

## 7. 防幻觉底线

- 只读**博主画在这张图上的**标注（圈/线/箭头/斜连/签名）。
- 规律只能从那条**线条轨迹本身**推导。
- **逐图（逐博主）隔离**，不带其它期上下文。
- **诚实至上**：推不出就写"无规律可推（博主疑乱画/巧合）"，**严禁为凑规律硬套历史走势**。
