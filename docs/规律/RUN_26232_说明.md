## 2. 命令链

```bash
D=data/crawl/20260830   # 先确认目录，以下均以 26232 为准

  --target-period 26232 --calib-period 26231 --calib-draw "1 8 7 9 9" \

  --date 20260830 --filter $D/filter_report.json --gate $D/blogger_hit_gate.json \
  --images $D/images --target-period 26232 --calib-period 26231 --out $D/strips

# ③ 视觉读博主目标期行手写单押（GLM）

  --date 20260830 --period 26232 --draw "8 0 2 3 3" \
```

## 3. 铁律（防幻觉，逐条遵守）

1. **真画规须读整张原图，把博主画的轨迹线读全**（圈选/连线/箭头/斜连/签名串）——链条读不全正是此前误判「巧合」的根因。
2. **🔴 值保真 ≠ 逻辑自洽**：预测必须是固定规律库（`REPEAT` 签名串重复 / `SWAP` 万十互换 / `SLANT` 同列等差）的**确定性输出**；推不出 → 判 **coincidence（巧合命中）**，即使中了也**不列规律**；链条含「模式用不到的节点」≥2 → 判**超伸**。
3. **🔴 签名串重复（博主亲手画出 291/1421 这类）= 合法规律**；**扫开奖历史表找「先例」= banned 幻觉**。区别只在：博主有没有**画出来**那条重复签名/轨迹线。
4. **位置判定用开奖表链条反推**（`draw_tbl[期号][位]==链数`，某列唯一成立即数学排他）；**勿用「像素 x 中心 vs `filter_report.cols`」**（被期号/和值列污染）。
5. **逐图（逐博主）隔离**，不带其它期上下文；**诚实至上**——推不出就写「无规律可推（博主疑乱画/巧合）」，**严禁为凑规律硬套历史走势**。
6. **链条约定**：`guihua_<期>_reproducible.json` 的 chains 只存博主画的**历史已开奖**节点（不含目标期预测节点），预测放 `predictions` 字段。
